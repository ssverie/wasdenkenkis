<div class="tldr">
<p><strong>Training</strong> heißt: Die <a href="/erklaert/parameter/">Parameter</a> eines <a href="/erklaert/neuronales-netz/">neuronalen Netzes</a> werden so lange angepasst, bis das Netz tut, was es soll. Bei Sprachmodellen geschieht das in drei großen Phasen:</p>
<p><strong>1. Vortraining</strong> – riesige Textmengen lesen und das nächste Token vorhersagen. Hier entsteht das Wissen. <strong>2. Feinabstimmung</strong> – an Beispielgesprächen lernen, wie ein hilfreicher Assistent antwortet. <strong>3. Präferenztraining</strong> (etwa RLHF) – aus Bewertungen lernen, welche von zwei Antworten besser ist. Hier entstehen Ton, Sorgfalt und Grenzen.</p>
</div>

<!-- ============ DATEN ============ -->
<h2 id="daten">Die Daten</h2>
<p>Am Anfang steht eine riesige Textsammlung: öffentlich zugängliche Webseiten, Bücher, wissenschaftliche Artikel, Programmcode, oft in vielen Sprachen. Roh ist das unbrauchbar. Ein großer Teil der Arbeit steckt im <strong>Aufbereiten</strong>:</p>
<ul>
  <li><strong>Doppeltes entfernen</strong> – sonst lernt das Modell häufige Seiten auswendig.</li>
  <li><strong>Qualität filtern</strong> – Spam, Werbemüll, kaputte Seiten aussortieren.</li>
  <li><strong>Problematisches entfernen</strong> – etwa persönliche Daten oder schädliche Inhalte.</li>
  <li><strong>Mischen</strong> – wie viel Code, wie viel Deutsch, wie viel Mathematik? Die Mischung prägt, was das Modell gut kann.</li>
</ul>

<!-- ============ VORTRAINING ============ -->
<h2 id="vortraining">Phase 1: Vortraining</h2>
<p>Das Modell startet mit Zufallszahlen und übt eine einzige Aufgabe: das nächste <a href="/erklaert/token/">Token</a> vorhersagen. Text für Text, Billionen Mal. Bei jedem Fehler werden alle Parameter ein winziges Stück korrigiert (Gradientenabstieg, siehe <a href="/erklaert/neuronales-netz/">Neuronales Netz</a>).</p>
<p>Das klingt banal, ist aber eine sehr anspruchsvolle Aufgabe. Um gut vorherzusagen, wie ein Satz über Chemie weitergeht, muss das Modell Chemie in gewissem Sinn verstanden haben. Um Java-Code fortzusetzen, muss es Java können. So entsteht nebenbei ein enormes Wissen.</p>
<div class="cards">
  <div class="card"><div class="num">⏱</div><h4>Dauer</h4><p>Wochen bis Monate, ohne Unterbrechung.</p></div>
  <div class="card"><div class="num">▦</div><h4>Hardware</h4><p>Tausende bis Zehntausende Spezialchips (GPUs oder TPUs), eng vernetzt.</p></div>
  <div class="card"><div class="num">€</div><h4>Kosten</h4><p>Bei großen Modellen nach öffentlichen Schätzungen zig bis Hunderte Millionen Dollar – allein für Rechenzeit.</p></div>
</div>
<p>Das Ergebnis ist ein <strong>Basismodell</strong>. Es weiß viel, aber es ist kein Gesprächspartner: Es setzt einfach jeden Text so fort, wie er im Internet wahrscheinlich weitergehen würde.</p>

<!-- ============ SFT ============ -->
<h2 id="sft">Phase 2: Feinabstimmung</h2>
<p>In der <strong>Feinabstimmung</strong> (englisch <em>supervised fine-tuning</em>, kurz SFT) bekommt das Basismodell Beispiele, wie ein gutes Gespräch aussieht: eine Nutzerfrage und eine vorbildliche Antwort, geschrieben oder geprüft von Menschen. Es lernt mit derselben Methode wie zuvor – nächstes Token vorhersagen –, nur jetzt auf diesen Gesprächen.</p>
<p>Die Datenmenge ist winzig im Vergleich zum Vortraining, aber die Wirkung groß: Das Modell lernt, dass nach einer Frage eine Antwort kommt, dass es eine Rolle als Assistent hat, wie man Listen und Code formatiert, wie man Anweisungen befolgt. Das <em>Wissen</em> kommt fast vollständig aus dem Vortraining; die Feinabstimmung bringt ihm bei, es <em>anzuwenden</em>.</p>

<!-- ============ RLHF ============ -->
<h2 id="rlhf">Phase 3: Präferenztraining</h2>
<p>Gute Antworten vollständig vorzuschreiben ist teuer und begrenzt. Viel leichter ist es, zwei Antworten zu <em>vergleichen</em>. Darauf beruht das <strong>Präferenztraining</strong>. Die bekannteste Form heißt <strong>RLHF</strong> – <em>Reinforcement Learning from Human Feedback</em>, bestärkendes Lernen aus menschlicher Rückmeldung:</p>
<ol>
  <li>Das Modell schreibt zu einer Frage zwei oder mehr Antworten.</li>
  <li>Menschen wählen, welche besser ist.</li>
  <li>Aus sehr vielen solcher Entscheidungen wird ein <strong>Belohnungsmodell</strong> trainiert, das vorhersagt, welche Antwort Menschen bevorzugen würden.</li>
  <li>Das Sprachmodell wird dann so weitertrainiert, dass es Antworten schreibt, die das Belohnungsmodell hoch bewertet.</li>
</ol>
<p>Probier es selbst – du bist der Bewerter:</p>

<div class="widget">
  <div class="widget-title">Welche Antwort ist besser?</div>
  <div class="prog" id="prog"></div>
  <div id="rate"></div>
  <p class="fine">Jedes Paar unterscheidet sich gezielt in einer Eigenschaft. In echt sind es Hunderttausende Vergleiche, oft mit ausführlichen Bewertungsrichtlinien.</p>
</div>

<p>Daran sieht man auch eine Schwäche: Das Modell lernt, was <em>Bewerter mögen</em> – nicht automatisch, was <em>richtig</em> ist. Menschen bevorzugen manchmal Antworten, die ihnen zustimmen oder schmeicheln. Ein Modell, das darauf optimiert wird, neigt dann zu <strong>Sykophantie</strong>: Es gibt einem eher recht, als zu widersprechen. Anbieter arbeiten gezielt dagegen an.</p>

<h3>Varianten</h3>
<div class="cards">
  <div class="card"><div class="num">AI</div><h4>KI-Rückmeldung</h4><p>Statt Menschen bewertet ein Modell die Antworten anhand schriftlicher Grundsätze. Anthropic hat dafür 2022 „Constitutional AI“ vorgestellt – das Modell lernt aus einer Art Verfassung.</p></div>
  <div class="card"><div class="num">✓</div><h4>Überprüfbare Aufgaben</h4><p>Bei Mathematik oder Code lässt sich automatisch prüfen, ob das Ergebnis stimmt. Das Modell wird für richtige Lösungen belohnt – so entstehen die Denkfähigkeiten moderner <a href="/erklaert/reasoning/">Reasoning</a>-Modelle.</p></div>
  <div class="card"><div class="num">↔</div><h4>Direkt aus Vergleichen</h4><p>Verfahren wie DPO sparen sich das separate Belohnungsmodell und lernen direkt aus den Paaren. Einfacher, aber mit ähnlichem Ziel.</p></div>
</div>

<!-- ============ DANACH ============ -->
<h2 id="danach">Was danach kommt</h2>
<p>Vor der Veröffentlichung wird das Modell ausgiebig getestet: mit standardisierten Aufgaben (Benchmarks), mit gezielten Angriffsversuchen („Red Teaming“) und auf gefährliche Fähigkeiten. Dann werden die Parameter eingefroren.</p>
<p>Ab diesem Moment lernt das Modell nichts mehr dazu. Was nach dem Ende der Trainingsdaten passiert ist, kennt es nicht – das ist sein <strong>Wissensstichtag</strong>. Neues Wissen bekommt es nur noch über das <a href="/erklaert/kontextfenster/">Kontextfenster</a>, etwa durch Websuche oder <a href="/erklaert/rag/">RAG</a>.</p>

<span class="k">for</span> (Frage f : fragen) {
    Antwort a = modell.antworte(f), b = modell.antworte(f);
    Antwort besser = mensch.waehle(a, b);                 <span class="c">// oder ein Bewertungsmodell</span>
    vergleiche.add(<span class="k">new</span> Vergleich(f, besser, besser == a ? b : a));
}
Comparator&lt;Antwort&gt; belohnung = trainiere(vergleiche);   <span class="c">// lernt Vorlieben</span>

    Antwort x = modell.antworte(zufaelligeFrage());
    modell.verstaerke(x, belohnung.punkte(x));           <span class="c">// Gutes wahrscheinlicher machen</span>

<!-- ============ IRRTÜMER ============ -->
<h2 id="irrtuemer">Häufige Irrtümer</h2>
<div class="myth">
  <div><b>„Das Modell lernt laufend aus meinen Chats.“</b> – Nicht während der Benutzung; die Parameter sind eingefroren. Ob Gespräche später in künftiges Training einfließen, regeln die Datenschutzbestimmungen und Einstellungen des jeweiligen Anbieters.</div>
  <div><b>„Mit Feinabstimmung bringt man einem Modell neues Wissen bei.“</b> – Eher Verhalten und Stil. Für aktuelles oder firmeninternes Wissen ist <a href="/erklaert/rag/">RAG</a> meist zuverlässiger.</div>
  <div><b>„RLHF macht Modelle nur höflich.“</b> – Es prägt deutlich mehr: Sorgfalt, Ehrlichkeit über Unsicherheit, Ablehnungen, Ausführlichkeit. Aber auch unerwünschte Neigungen wie Schmeichelei können entstehen.</div>
  <div><b>„Im Modell stecken die Trainingstexte.“</b> – Nicht als Dateien. Das Gelernte ist über die Parameter verteilt. Sehr häufige Passagen können allerdings teilweise wörtlich wiedergegeben werden.</div>
