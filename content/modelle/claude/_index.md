Die Namen folgen einer Größenordnung aus der Dichtkunst: **Haiku** (kurzes Gedicht) ist das kleinste, **Sonnet** das mittlere, **Opus** (großes Werk) das größte der klassischen Reihe. **Fable** kam im Juni 2026 als neue Spitzenlinie dazu. Daneben gibt es **Mythos**, eine besonders leistungsfähige Linie, die nur eingeschränkt zugänglich ist.

Für Endkunden gibt es Abos (Pro, Max, Team, Enterprise). Die API-Preise oben gelten für Entwickler, die Claude in eigene Programme einbauen.

## Stärken

- **Programmieren und selbstständiges Arbeiten.** Mit Claude Code arbeitet Claude direkt in einem Softwareprojekt: Dateien lesen, Code ändern, Tests laufen lassen. Diese Seite ist auf genau diesem Weg entstanden.
- **Lange Dokumente.** Eine Million Tokens Kontext reicht für mehrere dicke Bücher oder eine ganze Codebasis auf einmal.
- **Schreiben.** Natürlicher Ton und gutes Deutsch, auch bei längeren Texten.
- **Offen gelegte Regeln.** Anthropic trainiert Claude nach einer veröffentlichten „Verfassung“ (Constitutional AI); die Fassung von 2026 hat rund 23.000 Wörter.

## Schwächen

- **Nur Text als Ausgabe.** Bilder, Sprache oder Video erzeugt Claude nicht selbst. Grafiken gehen nur als Code (zum Beispiel SVG).
- **Preis.** Die Spitzenmodelle gehören zu den teureren am Markt.
- **Wortreich.** Ein unabhängiger Test (Artificial Analysis) fand, dass Sonnet 5.5 pro Aufgabe sehr viele Tokens verbraucht – das kostet Zeit und Geld.
- **Wissensgrenze.** Was nach Juni 2026 passiert ist, weiß Claude nur, wenn es nachschlagen darf.
- **Vorsicht.** Selbsteinschätzung: Die eingebaute Vorsicht schützt, kann aber auch in unnötige Rückfragen oder Ablehnungen umschlagen.
